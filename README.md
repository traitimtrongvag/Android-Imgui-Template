# Android ImGui Template

This branch is dedicated to ImGui UI testing. You can download the test APK [Here](https://www.mediafire.com/file/tfxunuspc4glpj2/ImGUI+test.apk/file), then replace the APK's `libtest.so` with your own library 😊.

See [Input Flow](InputFlow.md) for more details 👀.

The original test APK was sourced from:
